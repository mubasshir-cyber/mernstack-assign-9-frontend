# Visitor Pass System Frontend (Assignment 9)

React.js web interface for the Visitor Pass Management System built with **Vite, React Router v6, Axios, and Lucide Icons**.

## Setup & Running

1. Navigate to frontend:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
